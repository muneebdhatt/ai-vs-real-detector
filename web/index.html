AI vs Real Image Detector

A deep learning project that classifies an image as real or AI-generated. The model runs entirely in your browser; your image is never uploaded.

Educational demo. It was trained on small 32×32 images from one generator, so it can be wrong on images from newer generators and on high-resolution photos. See the results table below.

Project links

Dataset

  • CIFAKE: 60,000 real images (from CIFAR-10) and 60,000 AI-generated images (Stable Diffusion), 32×32 pixels. Train set 100,000, test set 20,000.
  • Real-world test set (self-collected): real photos and images from free AI generators, used only for testing, never for training.
  • Dataset link: see links above

Model and code

  • Baseline: custom CNN (4 conv blocks, batch norm, dropout).
  • Main model: MobileNetV2 pretrained on ImageNet, head trained first, then the top 30 layers fine-tuned at a learning rate of 1e-5.
  • Input: 128×128 RGB. Output: probability the image is real (sigmoid). Threshold 0.5.
  • Deployment: exported to TensorFlow.js and run in the browser.
  • Source code, notebooks and weights are in the GitHub repository.
