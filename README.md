# AI vs Real Image Detector

Deep learning semester project. A model that classifies an image as **real** or **AI-generated**, deployed as a website that runs the model in the browser.

## Problem
Given an image, predict whether it is a real photograph or generated by an AI model. Output: label and confidence.

## Dataset
- **CIFAKE** (Kaggle): https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images
  60,000 real (CIFAR-10) + 60,000 AI-generated (Stable Diffusion) images, 32x32. Train 100,000 / test 20,000.
  The dataset is not stored in this repo. Run `python src/download_data.py` to fetch it.
- **Real-world test set (self-collected):** images in `realworld_test/real` (real photos) and `realworld_test/ai` (images from free AI generators). Used only for testing. Sources are listed in `realworld_test/sources.csv`.

## Models
| Model | Description |
|---|---|
| Baseline | Custom CNN: 4 conv blocks (32-64-128-256), batch norm, dropout, sigmoid |
| Main | MobileNetV2 (ImageNet weights). Head trained first (lr 1e-3), then top 30 layers fine-tuned (lr 1e-5) |

Input 128x128 RGB, output P(real), threshold 0.5. Loss: binary cross-entropy. Optimizer: Adam. Early stopping on validation loss.

## How to run
```bash
pip install -r requirements.txt
python src/download_data.py                 # prints DATA_DIR
export DATA_DIR=<printed path>              # PowerShell: $env:DATA_DIR="<printed path>"

python src/train.py --model baseline --epochs 15
python src/train.py --model mobilenet --epochs 5 --finetune-epochs 8
python src/evaluate.py --model mobilenet
python src/gradcam.py --image path/to/image.jpg --out report/gradcam.png
python src/export_tfjs.py
```

### Predict with the trained weights
```bash
python src/predict.py --image sample.jpg
python src/predict.py --folder some_folder --model models/mobilenetv2.keras
```

## Deploy
Import this repo into Vercel and set **Root Directory** to `web`. No build command is needed (static site). The model is in `web/model/`.

## Limitations
CIFAKE images are tiny and come from a single generator, so the model can fail on high-resolution images and on newer generators. See the generalization-gap analysis in the report. This is an educational tool, not forensic evidence.
